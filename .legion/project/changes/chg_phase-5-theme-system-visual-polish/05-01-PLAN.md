# Plan 05-01: Theme Color Consolidation

<objective>
Agent: engineering-senior-developer

Add semantic color token groups to the theme system for diagnostics, search highlights,
breadcrumb accent, and fold indicators. Replace every hard-coded `Color32::from_rgb(...)`
in `view.rs` with theme token accessors so that switching dark↔light correctly updates
all visual elements.
</objective>

<context>
## Phase Context
Phase 5: Theme System & Visual Polish. Theme infrastructure (Theme struct, dark/light
constructors, settings wiring) is already complete. This plan addresses the ~8 sites
in `view.rs` that bypass the token system with hard-coded colors.

## Existing Theme Token Architecture
- `crates/legion-desktop/src/theme.rs` — `Theme` struct with `BackgroundTokens`,
  `BorderTokens`, `TextTokens`, `AccentTokens`, `SpacingScale`, `RadiusScale`,
  `TypographyScale`. `tokens()` global accessor. `install()` applying to egui.
- Dark and light constructors at `Theme::dark()` (line 56) and `Theme::light()` (line 102).
- `token_color()` at `view.rs:3204-3218` maps `ViewportSemanticTokenKind` → theme accent colors.
- Already-correct: syntax token colors go through `token_color()`.

## Hard-Coded Color Sites to Fix
1. Diagnostic severity colors at `view.rs:~2926-2929` (Error=255,80,80 Warning=255,165,0 Info=0,120,215 Hint=150,150,150) — severity underline painting
2. Same diagnostic colors repeated at `view.rs:~2990-2993` — inline diagnostic squiggles
3. Find match highlight yellow at `view.rs:~2855` (`Color32::from_rgba_premultiplied(255, 235, 59, 80)`)
4. Current match highlight orange at `view.rs:~2856` (`Color32::from_rgba_premultiplied(255, 152, 0, 120)`)
5. Breadcrumb accent at `view.rs:~2581` (`Color32::from_rgb(75, 156, 211)`)
6. Fold-range gutter indicator at `view.rs:~3034` (`Color32::from_rgba_premultiplied(150, 150, 150, 128)`)

## Codebase Conventions
- Theme token structs use `pub(crate)` visibility
- Color values use `Color32::from_rgb()` or `Color32::from_rgba_unmultiplied_const()`
- Both `dark()` and `light()` are `const fn` — new tokens must use `const`-compatible constructors
- `theme::dim(color, alpha)` exists for alpha-dimming at `theme.rs:562`
</context>

## Task 1: Add Semantic Token Groups to Theme

### Actions
1. Read `crates/legion-desktop/src/theme.rs` fully
2. Add `DiagnosticTokens` struct after `AccentTokens`:
   ```rust
   pub(crate) struct DiagnosticTokens {
       pub(crate) error: Color32,
       pub(crate) warning: Color32,
       pub(crate) info: Color32,
       pub(crate) hint: Color32,
   }
   ```
3. Add `SearchTokens` struct:
   ```rust
   pub(crate) struct SearchTokens {
       pub(crate) match_highlight: Color32,
       pub(crate) current_match: Color32,
   }
   ```
4. Add `ChromeTokens` struct for breadcrumb accent, fold indicator, and future chrome colors:
   ```rust
   pub(crate) struct ChromeTokens {
       pub(crate) breadcrumb_accent: Color32,
       pub(crate) fold_indicator: Color32,
   }
   ```
5. Add `diagnostic`, `search`, and `chrome` fields to `Theme` struct
6. Populate dark values in `Theme::dark()`:
   - diagnostic: error=255,92,122 (reuse accent.red), warning=255,184,107 (reuse accent.orange), info=75,140,255 (reuse accent.blue), hint=126,129,144 (reuse text.muted)
   - search: match_highlight via `Color32::from_rgba_unmultiplied_const(255, 235, 59, 80)`, current_match via `Color32::from_rgba_unmultiplied_const(255, 152, 0, 120)`
   - chrome: breadcrumb_accent=75,156,211, fold_indicator via `Color32::from_rgba_unmultiplied_const(150, 150, 150, 128)`
   - CRITICAL: `Theme::dark()` and `Theme::light()` are `const fn`. All color values MUST use
     `Color32::from_rgb()` or `Color32::from_rgba_unmultiplied_const()` — NOT `from_rgba_premultiplied()`
     which is not const-compatible in egui 0.34.2.
7. Populate light values in `Theme::light()` with adjusted colors appropriate for light backgrounds:
   - diagnostic: error=212,24,61 (reuse accent.red), warning=180,91,18 (reuse accent.orange), info=38,100,214 (reuse accent.blue), hint=113,113,130 (reuse text.muted)
   - search: match_highlight via `Color32::from_rgba_unmultiplied_const(255, 235, 59, 100)` (slightly more opaque on light bg), current_match via `Color32::from_rgba_unmultiplied_const(255, 152, 0, 140)`
   - chrome: breadcrumb_accent=38,100,214, fold_indicator via `Color32::from_rgba_unmultiplied_const(113, 113, 130, 128)`
