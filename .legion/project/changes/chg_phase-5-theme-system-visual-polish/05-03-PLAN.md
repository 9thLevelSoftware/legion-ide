- Plan 05-01 SUMMARY.md — theme colors consolidated, `tokens().search`, `tokens().chrome` available
- Plan 05-02 SUMMARY.md — tab bar polished with close buttons, overflow scroll, drag reorder

## Design Direction
- Minimap renders as a narrow panel (80-120px) to the right of the code area
- Each buffer line is represented as ~1px height colored blocks (using syntax token colors at reduced opacity)
- Viewport indicator is a semi-transparent rectangle showing the currently visible line range
- Click anywhere on the minimap scrolls the editor to center that position
- Uses `tokens().bg.code` for minimap background, `tokens().search.match_highlight` for find matches in minimap
</context>

<tasks>
## Task 1: Render Minimap Overview

### Actions
1. Read `crates/legion-desktop/src/view.rs` — find the minimap stub (around line 2404)
2. Read the code area rendering to understand how buffer data flows to the viewport
3. Replace the stub with `render_minimap()`:
   - Allocate a fixed-width panel (100px) to the right of the code area
   - Background: `tokens().bg.code`
   - For each line in the buffer (up to `line_count`):
     - Calculate y position: `line_index * scale` where `scale = panel_height / total_lines` (clamped to min 1px per line)
     - If the line has semantic token overlays, paint colored rectangles using `token_color()` at reduced opacity (~40%)
     - If no semantic data, paint a short gray bar representing text width
   - For large files (>10K lines), use sampling: render every Nth line to keep minimap responsive
   - IMPORTANT: Large files in degraded mode have `small_buffer_preview = None` and limited
     `ViewportProjection.lines`. The minimap must handle this gracefully — show the minimap panel
     with a proportional viewport indicator based on `line_count` from metadata, but render
     only the lines available from the viewport projection (not the full buffer). If no line data
     is available at all, show an empty minimap background with just the viewport indicator.
4. Minimap only renders when `minimap_visible` is true in the settings model
5. When minimap is hidden, the code area gets the full width

### Verify
```
cargo check -p legion-desktop
```

### Done
Minimap renders scaled-down colored representation of buffer content.

## Task 2: Viewport Indicator and Click Navigation

### Actions
1. Add viewport indicator rectangle to `render_minimap()`:
   - Calculate the visible range: `scroll.top_line` to `scroll.top_line + visible_line_count`
   - Draw a semi-transparent rectangle at the corresponding y range
   - Color: `tokens().bg.hover` at 60% opacity, border: `tokens().border.strong`
   - The indicator moves as the user scrolls the editor
2. Add click-to-scroll interaction:
   - Use `ui.interact(minimap_rect, minimap_id, egui::Sense::click())` on the minimap panel
   - On click: calculate target line from click y position → `clicked_line = (click_y / panel_height) * total_lines`
   - Fire `DesktopAction::SetViewportScroll { buffer_id, scroll: ViewportScroll { top_line: clicked_line, left_column: 0 } }`
   - Center the clicked line in the viewport: `target_top = clicked_line.saturating_sub(visible_lines / 2)`
3. Add drag-to-scroll: while mouse is pressed on minimap, continuously update scroll position
   - Use `response.dragged()` to detect ongoing drag
   - Update scroll on each frame during drag
