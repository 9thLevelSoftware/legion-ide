## Task 3: ANSI Parser — CSI, SGR, DEC Sequences

Implement `pub fn process(&mut self, data: &[u8])` on `TerminalEmulator`:

**Character handling**:
- Printable characters: write to current cursor position with current_attrs, advance cursor
- `\n` (LF): move cursor down; if at scroll_bottom, scroll up
- `\r` (CR): move cursor to column 0
- `\t` (TAB): advance to next tab stop (every 8 columns)
- `\x08` (BS): move cursor left one column (min 0)
- `\x07` (BEL): ignore (no audio)

**CSI sequences** (`\x1b[...`):
- Cursor movement: A (up), B (down), C (forward), D (back), H/f (absolute position), G (column), d (row)
- Erase: J (in display: 0=below, 1=above, 2=all, 3=all+scrollback), K (in line: 0=right, 1=left, 2=all)
- Insert/Delete: L (insert lines), M (delete lines), @ (insert chars), P (delete chars)
- Scroll: S (scroll up), T (scroll down)
- Set scroll region: r (DECSTBM)
- Cursor save/restore: s (save), u (restore)
- Device status: n (report cursor position → respond with `\x1b[row;colR`)

**SGR sequences** (`\x1b[...m`):
- 0: reset all attributes
- 1: bold, 2: dim, 3: italic, 4: underline, 7: inverse, 8: hidden, 9: strikethrough
- 22: normal intensity, 23: not italic, 24: not underline, 27: not inverse, 28: not hidden, 29: not strikethrough
- 30-37: standard foreground, 38;5;N: 256-color fg, 38;2;R;G;B: RGB fg
- 39: default foreground
- 40-47: standard background, 48;5;N: 256-color bg, 48;2;R;G;B: RGB bg
- 49: default background
- 90-97: bright foreground, 100-107: bright background

**DEC private modes** (`\x1b[?...h` to set, `\x1b[?...l` to reset):
- 1: application cursor keys (DECCKM)
- 7: auto-wrap (DECAWM)
- 12: cursor blink (ignore)
- 25: cursor visibility (DECTCEM)
- 1049: alt screen buffer (save cursor + switch to alt + clear)

**Parser state machine**:
- Ground state → ESC seen → CSI started → parameter collection → dispatch
- Handle partial sequences: if buffer ends mid-sequence, save state and resume on next `process()` call
- Unknown/unsupported sequences: consume and discard silently
