<objective>
Wire the VT100 emulator (from Plan 02-01) into the terminal output pipeline, render the cell grid with per-cell colors in egui, and translate keyboard input to terminal escape sequences.

</objective>

## Task 1: Wire Emulator into Terminal Output Pipeline

Modify `crates/legion-terminal/src/lib.rs`:

1. Add a `TerminalEmulator` instance per terminal session in `TerminalRuntime`:
   - Store `HashMap<SessionId, TerminalEmulator>` alongside existing session state
   - Create emulator on session launch with the terminal's column/row dimensions
   - On resize: call `emulator.resize(cols, rows)`
   - On session close: remove emulator

2. In `poll_output()`, after `redact_terminal_projection()`:
   - Feed the redacted output bytes into the session's emulator via `emulator.process(bytes)`
   - The emulator's grid is now the source of truth for display

3. Add a method to expose the emulator's grid for rendering:
   - `pub fn emulator_grid(&self, session_id: &str) -> Option<&TerminalEmulator>`
   - The desktop layer reads this to render colored cells

4. Update `TerminalOutputRowProjection` in `crates/legion-protocol/src/lib.rs`:
   - Add `pub cell_rows: Option<Vec<CellRow>>` where `CellRow` contains cells with attributes
   - Keep `redacted_payload` for backward compatibility and text-only consumers
   - Add the cell attribute types to protocol (or reference legion-terminal types)

**Verify**: `cargo check -p legion-terminal`

## Task 2: Render Cell Grid with Per-Cell Colors in egui

Modify `crates/legion-desktop/src/view.rs`:

1. Update `render_terminal_stream()` (~line 3991):
   - Check if emulator grid data is available in the projection
   - If yes: render using new cell-grid path (below)
   - If no: fall back to existing text-row rendering (preserve current behavior)

2. New cell-grid rendering path:
   - For each row in the emulator grid (visible area + scrollback):
     - For each cell in the row:
       - Map `Color::Indexed(n)` to egui `Color32` using a standard 256-color table
       - Map `Color::Rgb(r,g,b)` directly to `Color32`
       - Map `Color::Default` to theme foreground/background
     - Build an egui `LayoutJob` with `TextFormat` per color-run (consecutive cells with same attributes)
     - Apply bold via font weight, italic via font style, underline via underline stroke
     - Apply inverse by swapping fg/bg colors
   - Use monospace font (`theme::code()` family) for all terminal text
   - Render cursor as a block/line at the cursor position (solid for focused, outline for unfocused)

3. Update `render_terminal_payload()` (~line 4167):
   - Keep URL detection working — scan the text content of cells for URLs
   - URLs still get clickable treatment on top of colored rendering

4. Modify `crates/legion-desktop/src/view/terminal_panel.rs`:
   - Update `TerminalPanelRenderModel` to carry the cell grid data alongside the text grid
   - `from_projection()` passes through cell data when available

**Verify**: `cargo check -p legion-desktop`

## Task 3: Translate Keyboard Input to Terminal Escape Sequences

Modify `crates/legion-desktop/src/view/interactive_fields.rs`:

1. Replace the simple `TextEdit::singleline` with a raw keyboard event handler:
   - When the terminal panel is focused, capture egui key events directly
   - Printable characters: send as UTF-8 bytes
   - Enter: send `\r` (not `\r\n` — the PTY handles line discipline)
   - Backspace: send `\x7f` (or `\x08` depending on terminal mode)
   - Tab: send `\t`
   - Escape: send `\x1b`

2. Arrow keys and navigation — translate to ANSI escape sequences:
   - Arrow Up: `\x1b[A` (normal) or `\x1bOA` (application cursor mode)
   - Arrow Down: `\x1b[B` / `\x1bOB`
   - Arrow Right: `\x1b[C` / `\x1bOC`
   - Arrow Left: `\x1b[D` / `\x1bOD`
   - Home: `\x1b[H`
   - End: `\x1b[F`
   - Page Up: `\x1b[5~`
   - Page Down: `\x1b[6~`
   - Insert: `\x1b[2~`
   - Delete: `\x1b[3~`

3. Function keys:
   - F1-F4: `\x1bOP` through `\x1bOS`
   - F5-F12: `\x1b[15~` through `\x1b[24~`

4. Modifier combinations:
   - Ctrl+C: send `\x03` (interrupt)
   - Ctrl+D: send `\x04` (EOF)
   - Ctrl+Z: send `\x1a` (suspend)
   - Ctrl+L: send `\x0c` (clear)
   - Ctrl+A through Ctrl+Z: send `\x01` through `\x1a`

5. Query the emulator's `application_cursor_keys` mode to determine which escape variant to send for arrow keys.

**Verify**: `cargo check -p legion-desktop` and manual test — arrow keys work in the terminal
