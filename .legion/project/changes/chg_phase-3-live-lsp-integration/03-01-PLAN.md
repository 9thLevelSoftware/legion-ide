## Task 2: Render Inline Diagnostic Underlines

Read `crates/legion-desktop/src/view.rs`, find `paint_current_line_highlight()` and `paint_code_cursor()` to understand the overlay painting pattern (they use `ui.painter()` to draw shapes on top of the galley response rect).

Add a function `paint_diagnostic_underlines` in `view.rs`:

```rust
fn paint_diagnostic_underlines(
    ui: &egui::Ui,
    line: &CodeLineProjection,
    response: &egui::Response,
    problems: &[LanguageProblemProjection],
    char_width: f32,
)
```

Implementation:
1. Filter `problems` to those whose `range` overlaps with `line.number` (remember: `TextCoordinate.line` is 0-based, `line.number` is 1-based, so compare `problem.range.start.line + 1 <= line.number && problem.range.end.line + 1 >= line.number`)
2. For each matching problem, compute pixel x-coordinates:
   - `start_x = response.rect.left() + (start_char as f32 * char_width)` where `start_char` is the problem's start character on this line (or 0 if the problem starts on an earlier line)
   - `end_x = response.rect.left() + (end_char as f32 * char_width)` where `end_char` is the problem's end character on this line (or the line length if the problem continues past this line)
3. Paint a straight colored underline 2px below the text baseline:
   - `let y = response.rect.bottom() - 1.0;`
   - Color by severity:
     - `Error` → `Color32::from_rgb(255, 80, 80)` (red)
     - `Warning` → `Color32::from_rgb(255, 165, 0)` (orange)
     - `Info` → `Color32::from_rgb(0, 120, 215)` (blue)
     - `Hint` → `Color32::from_rgb(150, 150, 150)` (gray)
   - Use `ui.painter().line_segment([pos2(start_x, y), pos2(end_x, y)], Stroke::new(1.5, color));`

Call `paint_diagnostic_underlines` inside `render_code_lines()`, after `paint_code_cursor()` (around line 2246), passing `&snapshot.language_tooling_projection.problems`.

**Verify**: `cargo check -p legion-desktop`

## Task 3: Diagnostic Hover Tooltip

Add a function `show_diagnostic_tooltip` in `view.rs`:

```rust
fn show_diagnostic_tooltip(
    ui: &egui::Ui,
    response: &egui::Response,
    line: &CodeLineProjection,
    problems: &[LanguageProblemProjection],
    char_width: f32,
)
```

Implementation:
1. Only proceed if `response.hovered()` — early return otherwise
2. Get hover position: `response.hover_pos()` → compute the character column as `((hover_x - response.rect.left()) / char_width) as u32`
3. Find all problems whose range contains this (line, column) position (same line overlap logic as Task 2, plus column within range)
4. If any problems match, use `egui::show_tooltip_at_pointer(ui.ctx(), ui.id().with("diag_tooltip"), |ui| { ... })`:
   - For each matching problem:
     - Show severity label in matching color: `ui.colored_label(color, format!("{:?}", problem.severity));`
     - Show message: `ui.label(&problem.message);`
     - If `problem.source_label.is_some()`: show source in muted text
     - If `problem.code_label.is_some()`: show code in muted text
   - If multiple problems, add a separator between each

Call `show_diagnostic_tooltip` inside `render_code_lines()`, immediately after `paint_diagnostic_underlines`.
